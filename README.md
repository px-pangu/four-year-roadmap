# 四年路线图 · 大学生成长路径规划器

> 12 道单选题，2 分钟出初版；把「我该保研还是就业」拆成 **八学期、每学期 ≤ 3 个能今天就做的动作**。

## 1. 这是什么

面向大一到大四学生的**成长路径规划器**。它刻意不做三件事：不制造焦虑、不给人排名、不给唯一正确答案。

输入 12 项个人参数后，页面会输出：

1. **四类资产进度盘** —— GPA / 竞赛 / 科研 / 实习，显示当前值、目标值与「已走完 X%」；
2. **同专业匿名对标** —— 只给分位数，不显示任何他人数据；
3. **关键节点倒计时** —— 按赛道取 4 个节点，自动推算到下一年，各挂 3 条材料清单；
4. **八学期路线图** —— 八张学期卡，字段固定为【学期 / 主线任务 / 关键动作（≤3 条）/ 所需资源·入口 / 常见坑 / 自检问题】。

覆盖 **5 条赛道 × 8 学期 = 40 条路径**（每条大四下另有 3 种收尾路径可选）。

### 当前版本的性质

- 单文件纯前端，双击 `index.html` 即可运行，**不含任何外部网络请求**；
- 问卷答案与勾选状态保存在浏览器 **localStorage** 中，不注册、不上传；
- 对标分位数为**演示样本**，界面上常驻展示样本量 n 与统计口径，正式使用须替换为经授权的一手数据；
- 节点日期按当前日期自动推算，只精确到月/日，**以各校官网公告为准**。

## 4. 功能模块详解

### 01 十二题输入问卷

- **12 道单选**：学期、专业门类、主赛道、备选赛道、GPA 档、排名档、英语档、竞赛级别、科研阶段、实践段数、每周自修时长、最想解决的一件事。
- **常驻提示**：顶部显示「已答 n/12」与剩余学期数；答满即出图，**答完可改，路线图实时重算**。
- **产出物**：四资产当前值、主/备选赛道标签、个人化提醒语。
- **风险预案**：GPA 提供「还不清楚」档并按保守值 3.00 估算，且**明确标注「保守估计」**——不让估算值伪装成精确值。

### 02 四类资产进度盘

- **四项**：GPA / 竞赛 / 科研 / 实习，显示当前值、本赛道目标值与完成百分比。
- **设计**：进度条末端有目标刻度线，达标显示「已到达目标区间」；目标值随赛道切换而变，用于对照不同赛道的投入结构。
- **文案口径**：只说「还差多少」，不说「危险 / 落后」。

### 03 同专业匿名对标

- **只显示综合分位数 Pxx** 与「前 / 后百分之多少」；分位轴上**只标出「你」这一个点**。
- 常驻展示样本量 n 与统计口径，并标注为**演示样本**。
- **风险预案**：口径文案固定在卡片内**不可折叠**，正式部署须替换为经授权的一手数据并同步更新 n。

### 04 关键节点倒计时与材料清单

- 按赛道取 4 个节点（如夏令营、预推免、初试、秋招），日期自动推算到下一年，显示剩余天数。
- 每个节点挂 3 条材料清单，可勾选并存在本机；已过节点降低透明度保留，**不作删除**。
- **风险预案**：只显示到「月/日」，注明以各校官网公告为准，不提供官方时间承诺。

### 05 八学期路线图时间轴

- 八张学期卡，字段固定为【学期、主线任务、关键动作（≤3 条）、所需资源/入口、常见坑、自检问题】。
- 当前学期高亮，已过学期降透明度作回顾位；**每张卡右下显示实际字数与 200 字上限**。
- **第 8 张卡按赛道展开三种收尾路径**（就业签约 / 读研过渡 / gap 年准备），可手动切换另外两条对照。
- 一键导出 Markdown 路线图。
- **风险预案**：动作给太多会变成新的焦虑源 → 硬上限 3 条，且每条自带入口资源与自检问题，**不做完成度打分**。

## 5. 五条赛道与收尾路径

| 赛道 | 主线逻辑 | 大四下默认收尾路径 |
|---|---|---|
| 保研 | 前三年权重最高，把成绩、科研与材料做扎实 | 读研过渡 |
| 考研 | 一次考试决定结果，关键是科目节奏与信息收敛 | 读研过渡 |
| 留学 | GPA、语言、科研与实践四条线并行，材料周期长 | 读研过渡 |
| 就业 | 以岗位 JD 为锚，用经历与作品把简历填满 | 就业签约 |
| 创业 | 以真实验证为主，学业与现金流是两条兜底线 | gap 年准备 |

三条收尾路径**无优劣之分**，可随时手动切换对照。

## 7. 硬约束（设计红线）

1. **不使用焦虑话术** —— 禁止「再不 XX 就完了」「你的同龄人已经…」；
2. **不展示任何他人姓名、学号与成绩** —— 对标只给分位数；
3. **不输出唯一「正确答案」赛道** —— 五条主线可随时切换对照；
4. **所有对标数据必须同时标注样本量与统计口径**；
5. **进度一律用进度条，不使用红黄绿告警配色**。

---

## 8. 数据持久化与隐私

| 项 | 说明 |
|---|---|
| 存储位置 | 浏览器 `localStorage` |
| 保存内容 | 12 题答案、材料清单勾选状态 |
| 上传 | **不注册、不上传、不追踪** |
| 丢失 | 换浏览器或清理浏览器数据会丢失 |

---

## 9. 已知限制

- 对标分位数来自演示样本，非真实统计；
- 节点日期为按当前日期的自动推算，未经各校校历校准；
- 卡片字数上限校验：当前最大 198 字（第 8 张卡 · 就业签约路径），40 条路径均在 200 字以内。
