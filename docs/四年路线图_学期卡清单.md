# 四年路线图 · 大学生成长路径规划器 — 学期卡清单

**全局基线**：12 道单选题 ≤ 2 分钟出初版；八学期时间轴每学期 ≤ 3 个关键动作、每张卡 ≤ 200 字；全站单页滚动，无分页、无弹窗式向导。
**硬约束**：① 不使用焦虑话术（禁止「再不 XX 就完了」「你的同龄人已经…」）；② 不展示任何他人姓名、学号与成绩，对标只给分位数；③ 不输出唯一「正确答案」赛道，五条主线可随时切换对照；④ 所有对标数据必须同时标注样本量与统计口径；⑤ 进度一律用进度条，不使用红黄绿告警配色。
**迭代说明**：第 8 张卡（大四下）由「统一的毕业与求职收尾建议」调整为「按用户所选赛道分别给出三种收尾路径（就业签约 / 读研过渡 / gap 年准备），每条路径各附 2 条风险提示」，其余 7 张卡与全部模块保持不变。
**视觉基调**：浅米色底 #F6F1E6 + 深绿主色 #1F4E3D，暖陶土 #A9673C 作点缀；圆角卡片、细描边、无告警色；数字与字段名用等宽字体作「理性」锚点。

### 01 十二题输入问卷

- **用户场景与痛点**：大一到大四的焦虑是模糊的（「我该保研还是就业」），但传统咨询要先填一页纸的背景资料。
- **核心功能**：① 12 道单选：学期、专业门类、主赛道、备选赛道、GPA 档、排名档、英语档、竞赛级别、科研阶段、实践段数、每周自修时长、最想解决的一件事；② 顶部常驻「已答 n/12」与剩余学期数；③ 答满即出图，答完可改，路线图实时重算。
- **产出物**：四资产当前值、主/备选赛道标签、个人化提醒语（按「最想解决的一件事」）。
- **风险与预案**：用户凭感觉乱填导致路线失真。预案=GPA 提供「还不清楚」档并按保守值 3.00 估算，且明确标注「保守估计」，不让估算值伪装成精确值。

### 02 四类资产进度盘

- **用户场景与痛点**：知道要「提升背景」，但不知道自己离目标差多少、差在哪一项。
- **核心功能**：① GPA / 竞赛 / 科研 / 实习四项，显示当前值、本赛道目标值与「已走完 X%」；② 进度条末端有目标刻度线，达标显示「已到达目标区间」；③ 目标值随赛道切换而变，用于对照不同赛道的投入结构。
- **产出物**：四条进度条 + 差值描述（只说「还差多少」，不说「危险 / 落后」）。
- **风险与预案**：进度条被误读为「红黄绿灯」。预案=全站只用深绿渐变填充，差值文案统一为中性陈述，禁用「预警、落后、危险」类词。

### 03 同专业匿名对标

- **用户场景与痛点**：想知道自己在同专业里大概什么位置，但看到别人具体分数会更焦虑。
- **核心功能**：① 按专业门类分组，只显示综合分位数 Pxx 与「前 / 后百分之多少」；② 分位轴上只标出「你」这一个点，不显示任何他人数据；③ 常驻展示样本量 n 与统计口径，并标注为演示样本。
- **产出物**：分位定位轴 + 口径说明条（含构成权重说明）。
- **风险与预案**：用户把演示样本当真实统计。预案=口径文案固定在卡片内不可折叠，正式部署须替换为经授权的一手数据并同步更新 n。

### 04 关键节点倒计时与材料清单

- **用户场景与痛点**：夏令营、预推免、初试、秋招这些时间点总是事后才知道。
- **核心功能**：① 按赛道取 4 个节点，日期按当前日期自动推算到下一年，显示剩余天数；② 每个节点挂 3 条材料清单，可勾选并存在本机；③ 已过节点降低透明度保留，不作删除。
- **产出物**：节点卡 ×4 + 材料勾选状态。
- **风险与预案**：节点日期因校历差异不准。预案=只显示到「月/日」并在说明中注明以各校官网公告为准，不提供官方时间承诺。

### 05 八学期路线图时间轴

- **用户场景与痛点**：建议看了一堆，落到具体的学期和动作上就空了。
- **核心功能**：① 八张学期卡，字段固定为【学期、主线任务、关键动作（≤3 条）、所需资源/入口、常见坑、自检问题】；② 当前学期高亮，已过学期降透明度作回顾位；③ 第 8 张卡按赛道展开三种收尾路径，可手动切换另外两条对照；④ 每张卡右下显示实际字数与 200 字上限。
- **产出物**：8 张学期卡 + 一键导出 Markdown 路线图。
- **风险与预案**：动作给太多变成新的焦虑源。预案=硬上限 3 条，且每条自带入口资源与自检问题，不做完成度打分。

## 赛道：留学（ABROAD）

## 附：字段口径与自检

- **字数口径**：统计「主线任务 + 关键动作 + 所需资源 + 常见坑 + 自检问题」五个字段的正文字符数，不含字段名与序号。当前最大值为 198 字（第 8 张卡 · 就业签约路径），全部 40 条路径均在 200 字以内。
- **动作数口径**：第 1 – 7 张卡每条 3 个动作；第 8 张卡每条路径 2 个动作 + 2 条风险提示，展开时不超过 3 条动作上限。
- **不出现的内容**：任何具体他人姓名、成绩、排名；任何「唯一正确赛道」结论；任何红黄绿告警配色；任何以「再不…就晚了」开头的句子。
